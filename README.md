## 🚀 استفاده

### آنلاین

[https://niksiratforex-ux.github.io/toolbox-plus/](https://mohsen-niksirat.github.io/Toolbox/)

### نصب PWA

1. سایت رو در مرورگر باز کنید
2. روی آیکون Install یا افزودن به صفحه اصلی کلیک کنید
3. اپ مثل یک برنامه مستقل روی گوشی نصب میشه

### آفلاین

بعد از اولین بازدید، تمام ابزارها بدون اینترنت کار میکنند.

## 📁 ساختار پروژه

```
toolbox-plus/
├── index.html          ← اپلیکیشن اصلی (تک فایل)
├── manifest.json       ← PWA Manifest

├── README.md           ← این فایل
├── .nojekyll           ← GitHub Pages
```

## ⚙️ تکنولوژی‌ها

| تکنولوژی | کاربرد |
|----------|--------|
| Vanilla JS | بدون فریمورک |
