### نصب PWA روی گوشی

۱. لینک بالا را در **Chrome** یا **Safari** باز کنید  
۲. در Chrome: روی **⋮ منو → افزودن به صفحه اصلی** کلیک کنید  
۳. در Safari (iOS): روی **Share → Add to Home Screen** کلیک کنید  
۴. اپلیکیشن مثل یک برنامه مستقل نصب می‌شود و **آفلاین** هم کار می‌کند!

### بروزرسانی خودکار

- وقتی نسخه جدید منتشر شود، یک **بنر بنفش** پایین صفحه ظاهر می‌شود: «نسخه جدید آماده است!»
- با کلیک روی آن، کش قدیمی پاک شده و نسخه جدید بارگذاری می‌شود
- نیازی به Uninstall و Install مجدد نیست!
