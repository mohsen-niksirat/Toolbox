### ✨ ویژگی‌ها

- 🔢 **۱۵۱ ابزار** در **۱۴ دسته**
- 🌐 **چندزبانه** — فارسی و انگلیسی با قابلیت تعویض یک‌کلیکه
- 🌙 **تم تاریک/روشن** با ذخیره خودکار
- 📱 **ریسپانسیو و بهینه برای تاچ موبایل**

- 🔄 **بروزرسانی خودکار** — پاکسازی کش قدیمی با یک کلیک
- 🔍 **جستجوی هوشمند** در تمام ابزارها
- ⭐ **علاقه‌مندی‌ها + ابزارهای اخیر**
- 📦 **تک فایل HTML** — بدون npm یا فریمورک

## English

**151 useful tools** in one web app — single-file, bilingual (FA/EN), PWA, works offline

### ✨ Features

- 🔢 **151 tools** in **14 categories**
- 🌐 **Bilingual** — Persian and English, switch with one click
- 🌙 **Dark/Light theme** with auto-save
- 📱 **Responsive & touch-optimized** for mobile
- ⚡ **PWA** — installable, works offline
- 🔄 **Auto-update** — old cache cleared automatically
- 🔍 **Smart search** across all tools
- ⭐ **Favorites + recent tools**
- 📦 **Single HTML file** — no npm or framework
- 🎮 **23 games** with touch support
- ⚙️ **Settings panel** — font, size, export/import, stats
- 🩺 **Tool Health Check** — browser status, cache, capabilities
- ✨ **Discovery mode** — 3 random tools daily
- 🎓 **Guided tour** for new users
- 🔀 **Split View** — use two tools side by side

### 🚀 Install PWA

1. Open the link in Chrome or Safari  
2. **Chrome:** Menu → Add to Home Screen  
3. **Safari (iOS):** Share → Add to Home Screen  
4. The app installs and **works offline!**
